# APP

## Описание
Проект для генерации кода, обучения моделей и других задач, связанных с обработкой текста и кода.

## Установка
1. Клонируйте репозиторий:
   ```sh
   git clone <URL репозитория>
   cd APP
   ```

2. Установите зависимости:
   ```sh
   pip install -r requirements.txt
   ```

3. Установите необходимые библиотеки для PyQt5:
   ```sh
   sudo apt-get update
   sudo apt-get install -y libgl1-mesa-glx libxcb-xinerama0 libxkbcommon-x11-0 libxcb-icccm4 libxcb-image0 libxcb-keysyms1 libxcb-render-util0 libxcb-xkb1
   ```

## Запуск
Для запуска приложения используйте следующую команду:
```sh
python -m machine_code_project.main
```
